GOMOKU 2026 (本格・五目並べ)
C#とGDI+による描画を駆使した、CPU対戦型五目並べアプリケーションです。
標準的な五目並べのルールに加え、高度なグラフィックス演出とAIアルゴリズムを搭載しています。

🌟 主な機能
インテリジェントAI対戦:

3つの難易度（初級・中級・上級）を搭載。

盤面のスコアリング評価アルゴリズムにより、プレイヤーの動きに応じた戦略的な着手を行います。

禁手判定システム:

黒番（プレイヤー）に対して「三三禁手」の制限を実装。競技ルールに近い緊張感を楽しめます。

カスタマイズ可能な外観:

標準石: シンプルで視認性の高いデザイン。

メタリック: 線形グラデーションを用いた、高級感のある質感。

オーディオフィードバック: 石を打つ際のSE（SoundPlayer）による臨場感のある演出。

スムーズなUX: ダブルバッファリングによる、チラつきのない描画処理。

🕹 遊び方
タイトル画面:

「初級」「中級」「上級」から難易度を選択。

石のスタイルを選択。

「対戦開始」をクリックしてゲームを始めます。

対戦中:

マウスで打ちたい場所（格子の交点）をクリックします。

右上の「タイトルへ」ボタンでいつでも設定をやり直せます。

勝利条件:

縦・横・斜めのいずれかに5つ石を並べれば勝利です。

🛠 技術仕様
描画エンジン: System.Drawing.Graphics (GDI+)

アンチエイリアス処理により、丸みのある滑らかな描画を実現。

AIロジック:

周囲の石の連結数と両端の空き状況をスキャンし、攻撃(Weight A)と防御(Weight D)の優先度を動的に計算。

禁手アルゴリズム:

プレイヤーの着手ごとに、四方に展開される「開いた三」の数をカウントし、不正な着手をリアルタイムで拒否。

🚀 実行環境
Windows OS

.NET Framework 4.7.2 以上 / .NET 6.0 以上 (Windows Forms)

stone.wav (SEファイル) を実行ファイルと同ディレクトリに配置することを推奨。
